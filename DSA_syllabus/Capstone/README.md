# Capstone Overview

**When:** Weeks 14–16  
**Mode:** Solo or pair  
**Pick one track** below. All tracks use the same deliverables and rubric.

## Deliverables
1. GitHub repo (or shared folder if GitHub blocked) with README
2. Clean analysis + modeling notebook(s)
3. Saved model artifact (optional but preferred)
4. Demo: Streamlit app **or** live notebook walkthrough
5. 8–10 minute presentation + 5-slide business brief
6. Short limitations / ethics reflection (½–1 page)
